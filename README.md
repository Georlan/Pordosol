# Pôr do Sol Alimentos — Landing Page

Landing page institucional da **Pôr do Sol Alimentos**, fabricante de massas sediada em Limoeiro do Norte, Ceará.

## Desenvolvimento

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```

## Estrutura

- `src/App.tsx`: conteúdo e estrutura principal da página.
- `src/styles.css`: direção visual e responsividade.
- `public/images/`: imagens oficiais derivadas do catálogo fornecido pela empresa.

## Conteúdo

Os dados de produtos, endereço, telefones, e-mail e claims de ausência de ovos/lactose/proteína animal foram baseados no catálogo fornecido para o projeto. Não generalizar esses claims para produtos em que eles não aparecem no material original.
